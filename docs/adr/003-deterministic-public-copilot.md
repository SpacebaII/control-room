# ADR 003: Deterministic public copilot

Status: accepted

Public copilot workflows use project-aware rules and templates. Live OpenAI assistance is restricted to the GitHub-allowlisted owner.

This preserves a complete public demonstration without visitor-driven model cost or unpredictable output. Both providers implement one proposal contract, so the review and application workflow remains identical. Deterministic language is less flexible, but it is evidence-backed, testable, and honest about its provider.
